# การกำกับดูแล: สิทธิ ความยินยอม และการถอนข้อมูล

[English](../en/governance.md) · [Español](../es/governance.md) · [Português](../pt/governance.md) · [Français](../fr/governance.md) · [Deutsch](../de/governance.md) · [Italiano](../it/governance.md) · [हिन्दी](../hi/governance.md) · [ไทย](../th/governance.md)

Uyari เก็บรักษาถ้อยคำและเสียงของผู้คน กฎเหล่านี้ใช้กับทุกภาษาและการมีส่วนร่วมทุกครั้ง
โดยยึดหลักความยินยอมโดยอิสระ ล่วงหน้า และได้รับข้อมูล (ปฏิญญาสหประชาชาติว่าด้วยสิทธิของชนเผ่าพื้นเมือง;
อนุสัญญา ILO ฉบับที่ 169) หลักการ CARE สำหรับการกำกับดูแลข้อมูลของชนพื้นเมือง
และกฎหมายของแต่ละประเทศที่มีการเก็บข้อมูล

## ใครเป็นผู้ตัดสินใจ

| บทบาท | ตัดสินใจเรื่อง |
|---|---|
| **ผู้ดูแลโครงการ (maintainer)** (หัวหน้าโครงการ) | โครงสร้าง สคีมา ตัวตรวจสอบ build และระเบียบวิธี |
| **ผู้ดูแลภาษา (steward)** (หนึ่งคนต่อหนึ่งภาษา เป็นคนที่พูดภาษานั้น) | ทุกเรื่องภายในภาษานั้น: ยอมรับการมีส่วนร่วม แต่งตั้งผู้ตรวจทาน บันทึกการถอนข้อมูล |
| **ผู้มีอำนาจของชุมชน** (ระบุชื่อไว้ใน `language.yaml`) | ให้ความยินยอมในนามของชุมชน และขอถอนข้อมูลได้ทุกเมื่อ |
| **ผู้มีส่วนร่วม (contributor)** (บุคคลหรือองค์กร) | จัดทำการมีส่วนร่วม และเลือกสัญญาอนุญาตร่วมกับชุมชน |

ไม่มีเอเจนต์ใดเป็นผู้ตัดสินใจ: Gatekeeper และ Trainer ทำได้เพียงให้คำแนะนำ และคนเป็นผู้ merge

## สัญญาอนุญาต

การมีส่วนร่วมแต่ละครั้งระบุสัญญาอนุญาตไว้ใน `contribution.yaml` และทุก build จะติดสัญญาอนุญาตนั้นไว้ในทุกแถว
เพื่อให้ทุกคนที่ใช้ข้อมูลกรองตามสัญญาอนุญาตได้

* ค่าเริ่มต้น: **CC BY 4.0** ชุมชนอาจเลือก CC BY-SA 4.0, CC BY-NC 4.0, CC0 หรือสัญญาอนุญาตของชุมชนเอง
* ผู้ดูแลภาษาอธิบายข้อได้เสียก่อนที่ชุมชนจะเลือก: สัญญาอนุญาตแบบไม่ใช้เชิงพาณิชย์จะทำให้บริษัทนำเครื่องแปล
  ไปติดตั้งให้กระทรวงหรือคลินิกไม่ได้ ซึ่งมักเป็นช่องทางหลักที่เครื่องแปลจะไปถึงผู้คน
* โค้ดใช้ Apache 2.0 ส่วนน้ำหนักของโมเดล (model weights) ยังรับสัญญาอนุญาตของโมเดลพื้นฐานมาด้วย

## ความยินยอม

ความยินยอมมีทั้ง **ระดับชุมชน** (ผู้มีอำนาจของชุมชนยินยอมต่อวัตถุประสงค์และสัญญาอนุญาต) และ **รายบุคคล**
(ผู้แปลและผู้พูดที่เป็นผู้ใหญ่แต่ละคนยินยอมด้วยตนเอง) แบบฟอร์มอยู่ในโฟลเดอร์นี้ โดยใช้ชื่อไฟล์เดียวกันในทุกภาษา:

| แบบฟอร์ม | ผู้ให้ความยินยอม | ระบุไว้ใน |
|---|---|---|
| [`consent-collective.md`](consent-collective.md) | ผู้มีอำนาจของชุมชน | `contribution.yaml` → `consent.template` |
| [`consent-individual.md`](consent-individual.md) | ผู้แปลและผู้พูดแต่ละคน | `speakers.csv` → `consent_ref` |
| [`commissioned-work.md`](commissioned-work.md) | ผู้ที่ว่าจ้างและจ่ายค่างาน ในฐานะผู้ถือสิทธิ | `contribution.yaml` → `consent.template` |

`contribution.yaml` ระบุแบบฟอร์มด้วยชื่อไฟล์เท่านั้น (เช่น `consent-collective.md`) การอ้างอิงจึงใช้ได้เหมือนกันในทุกภาษา
ฉบับที่ลงนามแล้วเก็บไว้กับองค์กรที่ร่วมส่งข้อมูล ส่วน repository เก็บเพียงชื่อแบบฟอร์มและผู้มีอำนาจ
ไม่เก็บลายเซ็นหรือชื่อจริงเลย

## งานที่ว่าจ้าง

เมื่อคำแปลหรือเสียงบันทึกเป็นงานที่ว่าจ้างและจ่ายค่าตอบแทน ผู้จ่ายเงินเป็นผู้ถือสิทธิและเลือกสัญญาอนุญาต
มีการบันทึก `compensated: yes` แต่ไม่บันทึกจำนวนเงิน ตัวบุคคลที่ทำงานนั้นจะไม่ถูกระบุตัวตนใน repository
เสียงบันทึกของใครก็ตามต้องได้รับความยินยอมรายบุคคลจากคนนั้นด้วยเสมอ ไม่ว่าใครจะเป็นผู้จ่ายเงิน

## การถอนข้อมูล

ผู้ดูแลภาษาหรือผู้มีอำนาจของชุมชนสามารถขอให้นำการมีส่วนร่วมออกจากการฝึกโมเดลทั้งหมดในอนาคตได้
การถอนข้อมูลคือหนึ่งแถวใน [`contributing/takedowns.csv`](../takedowns.csv):

| คอลัมน์ | ความหมาย |
|---|---|
| `contribution` | id ของการมีส่วนร่วม |
| `requested_by_role` | `steward`, `community_authority`, `contributor` หรือ `maintainer` (เป็นบทบาท ไม่ใช่ชื่อคน) |
| `request_date`, `effective_date` | วันที่ยื่นคำขอ และวันที่ build เริ่มตัดข้อมูลนั้นออก |
| `scope` | `contribution`, `text` หรือ `audio` |
| `note` | ไม่บังคับ ห้ามมีข้อมูลส่วนบุคคล |

`uyari build` จะตัดการมีส่วนร่วมนั้นออกจากทุก build ที่มีวันที่ตรงกับหรือหลัง `effective_date`
โมเดลที่เผยแพร่ไปแล้วไม่สามารถเรียกคืนจากผู้ที่ดาวน์โหลดไปแล้วได้ แต่การ์ดของโมเดลจะได้รับการแก้ไข
และการฝึกครั้งถัดไปจะไม่ใช้ข้อมูลนั้นอีก

## การคุ้มครอง

* เฉพาะผู้ใหญ่เท่านั้น ใช้ id นามแฝง (`t-0001`, `s-0001`) ชื่อจริงเก็บไว้กับองค์กรที่ร่วมส่งข้อมูล
* ห้ามบันทึกเสียงของบุคคลที่สามที่ระบุตัวตนได้ ประโยคด้านสุขภาพบรรยายสถานการณ์ ไม่ใช่ผู้ป่วยจริง
* ไม่รวมชนพื้นเมืองที่อยู่โดดเดี่ยวโดยสมัครใจ
* ข้อมูลภาษาของชนพื้นเมืองจะไม่ถูกส่งไปยังโมเดลที่บุคคลภายนอกให้บริการซึ่งอาจนำข้อมูลไปฝึก:
  ทุกโมเดลใน `config/llm.yaml` ประกาศว่าตนเห็นข้อมูลอะไรได้บ้าง และโค้ดจะปฏิเสธกรณีอื่น
* การใช้งานที่ยอมรับได้: การเข้าถึงบริการ การศึกษา และการฟื้นฟูภาษา การใช้ข้อมูลหรือโมเดลเพื่อสอดแนม พุ่งเป้า
  หรือทำโปรไฟล์ผู้พูด ถือเป็นการละเมิดสัญญาอนุญาตในกรณีที่สัญญาอนุญาตกำหนดเงื่อนไขนั้นได้
  และเป็นการทำลายความไว้วางใจในกรณีที่กำหนดไม่ได้
