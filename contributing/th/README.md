# การมีส่วนร่วมกับ Uyari

[English](../en/README.md) · [Español](../es/README.md) · [Português](../pt/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Italiano](../it/README.md) · [हिन्दी](../hi/README.md) · [ไทย](../th/README.md)

Uyari รวบรวมคำแปลและเสียงบันทึก **ที่คนทำขึ้น** เพื่อให้ภาษาของชนพื้นเมืองและภาษาอื่นที่ยังขาดการรองรับ
มีเครื่องมือแปลแบบเปิด ทั้งข้อความและเสียงพูด แปลไปและกลับจากภาษาราชการที่ผู้พูดภาษานั้นต้องใช้
ในการรักษาพยาบาล การเรียน และการติดต่อราชการ ภาษาใดก็เข้าร่วมได้ การมีส่วนร่วมแต่ละครั้งคือหนึ่งโฟลเดอร์
ไม่จำเป็นต้องเขียนโปรแกรม

ก่อนมีส่วนร่วม โปรดอ่านกฎเรื่องสิทธิ ความยินยอม และการถอนข้อมูล: [governance.md](governance.md)

## สิ่งที่ต้องการตอนนี้

ทุกภาษามีไฟล์ `NEEDS.md` ที่ระบบอัปเดตให้เป็นปัจจุบันเสมอ ภาษาชาวี (Shawi) ของเปรูเป็นภาษาแรก
รายการของภาษานี้อยู่ที่ [`languages/cbt_Latn/NEEDS.md`](../../languages/cbt_Latn/NEEDS.md) ตอนนี้ต้องการ:

1. **เสียงอ่าน** คำแปลที่มีอยู่แล้ว โดยผู้ใหญ่อย่างน้อย 3 คน และได้รับความยินยอมจากพวกเขา
2. **ประโยคด้านสุขภาพและทะเบียนราษฎร์เพิ่มเติม** ที่แปลเป็นภาษาชาวี และมีผู้อ่านเจ้าของภาษาคนที่สองตรวจ

**หากต้องการเพิ่มภาษาใหม่** ให้เปิด issue ที่ระบุชื่อภาษา รหัส ISO 639-3 ภาษาราชการที่ผู้พูดภาษานั้นต้องใช้
และผู้ที่จะเป็นผู้ดูแลภาษา (steward) ได้ (คนที่พูดภาษานั้นและตรวจทานการมีส่วนร่วม)

## หนึ่งการมีส่วนร่วม = หนึ่งโฟลเดอร์ = หนึ่ง pull request

```
languages/<language>/contributions/<YYYY-MM>_<organization>_<nnnn>/
  contribution.yaml   who (pseudonym), when, how it was made, license, consent
  pairs.csv           chunk_id, text, replaces, translator_id, notes      (text)
  audio.csv           file, chunk_id, transcript, speaker_id, style, device, notes   (audio)
  speakers.csv        speaker_id, age_band, sex, first_language, consent_ref        (audio)
  wav/                16 or 48 kHz, mono, 16-bit, 1 to 20 seconds, one person per clip
```

* หนึ่งโฟลเดอร์มีภาษา **เดียว** วิธภาษา **เดียว** สัญญาอนุญาต **เดียว** และการอ้างอิงความยินยอม **เดียว**
* แปลจากประโยคภาษาราชการใน `primary/` (ตอนนี้คือภาษาสเปน `primary/spa_Latn/chunks/`)
  แต่ละแถวใน `pairs.csv` อ้างถึง `chunk_id` หนึ่งรายการ ให้แปลทั้งประโยค
* เขียนตัวอักษรของภาษาตามที่ `language.yaml` ของภาษานั้นกำหนด ตัวอย่างเช่น ในภาษาชาวี เสียงกักที่เส้นเสียง (glottal stop)
  เขียนเป็น **ʼ** (U+02BC) และ `uyari validate` จะบอกว่าต้องแปลง `'`, `’` หรือ `´` ตรงไหน
* **ห้ามนำคำแปลจากเครื่องหรือเสียงสังเคราะห์มาเสนอว่าเป็นงานของคน** ถ้ามีคนแก้ไขผลลัพธ์จากเครื่อง
  ให้ระบุใน `contribution.yaml` (`human_post_edited_from_mt`)
* เฉพาะผู้ใหญ่เท่านั้น ห้ามใส่ชื่อจริงในไฟล์ ให้ใช้ `t-0001`, `s-0001` องค์กรที่ร่วมส่งข้อมูลเก็บรายชื่อของตัวเอง
* การมีส่วนร่วมที่ได้รับการยอมรับแล้วจะไม่ถูกแก้ไขอีก การแก้ข้อผิดพลาดคือแถวใหม่ในการมีส่วนร่วมครั้งถัดไป
  ที่มี `replaces=<contribution>/<chunk_id>`

## เกิดอะไรขึ้นกับ pull request ของคุณ

1. **ตัวตรวจสอบ (validator)** (อัตโนมัติ): รูปแบบ รหัส id อะพอสทรอฟี และเสียง
2. **Gatekeeper** (อัตโนมัติ ใช้ Muse Glimmer บน GPU ของโครงการเอง): ตรวจว่ามีแถวที่ดูเหมือนภาษาราชการ
   แทนที่จะเป็นภาษาของชนพื้นเมือง หรือถูกคัดลอกมาหรือไม่ และเขียนรีวิวทีละแถวใน pull request
3. **ผู้ดูแลภาษา (steward)** อ่านรีวิว สุ่มตรวจบางแถว แล้วตัดสินใจ เนื้อหาด้านสุขภาพและการให้ความยินยอมโดยได้รับข้อมูล
   ต้องมีผู้อ่านเจ้าของภาษาคนที่สองเสมอ

หลังจาก merge แล้ว **Trainer** จะสร้างข้อมูลใหม่ ฝึกโมเดล วัดผล และเปิด pull request พร้อมผลลัพธ์

## การถอนข้อมูล

ผู้ดูแลภาษาหรือผู้มีอำนาจของชุมชนสามารถขอให้นำการมีส่วนร่วมออกจากการฝึกโมเดลทั้งหมดในอนาคตได้
โดยเพิ่มหนึ่งแถวใน [`contributing/takedowns.csv`](../takedowns.csv) โมเดลที่เผยแพร่ไปแล้วไม่สามารถเรียกคืนจากผู้ที่ดาวน์โหลดไปแล้วได้
แต่การ์ดของโมเดลจะได้รับการแก้ไข และการฝึกครั้งถัดไปจะไม่ใช้ข้อมูลนั้นอีก รายละเอียด: [governance.md](governance.md)

## การมีส่วนร่วมด้านโค้ด

```bash
uv sync --python 3.11 --extra dev --extra speech
uv run pytest -q
uv run ruff check src tests
git config core.hooksPath .githooks     # privacy check before every commit
```

งานที่ใช้ GPU ทำบน Ubuntu: [`docs/RUNBOOK-4090.md`](../../docs/RUNBOOK-4090.md) ทุกคำสั่งที่เรียก API แบบเสียเงิน
มี `--estimate` และใช้คีย์ของคุณเอง (`META_API_KEY`) และข้อมูลภาษาของชนพื้นเมืองจะไม่ถูกส่งไปยังโมเดลที่บุคคลภายนอกให้บริการ
(`data_policy` ใน `config/llm.yaml`)
