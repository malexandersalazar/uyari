# ความยินยอมระดับชุมชน (แบบฟอร์ม)

**ชุมชน / องค์กร:** ______________________  **ผู้มีอำนาจที่ลงนาม:** ______________________

1. **วัตถุประสงค์** คำแปลและเสียงบันทึกจะใช้สร้างเครื่องมือแปลแบบเปิดระหว่างภาษาของเรา
   กับภาษาราชการของประเทศเรา (ข้อความและเสียงพูด) เพื่อการเข้าถึงบริการ การศึกษา และการฟื้นฟูภาษาของเรา
2. **สัญญาอนุญาตที่เลือก** (เลือกหนึ่งข้อ): ☐ CC BY 4.0 ☐ CC BY-SA 4.0 ☐ CC BY-NC 4.0 ☐ สัญญาอนุญาตของชุมชน: ______
   สัญญาอนุญาตแบบไม่ใช้เชิงพาณิชย์จะทำให้บริษัทนำเครื่องแปลไปติดตั้งให้กระทรวงหรือสถานีอนามัยไม่ได้
3. **การใช้งานที่ยอมรับได้** ห้ามใช้ข้อมูลและโมเดลเพื่อสอดแนม ประหัตประหาร หรือทำโปรไฟล์ผู้พูด
4. **การถอนข้อมูล** ผู้มีอำนาจสามารถขอให้นำการมีส่วนร่วมออกจากการฝึกโมเดลทั้งหมดในอนาคตได้
   สิ่งที่เผยแพร่และมีผู้อื่นดาวน์โหลดไปแล้วไม่สามารถเรียกคืนได้
5. **บุคคล** เฉพาะผู้ใหญ่ และแต่ละคนต้องให้ความยินยอมรายบุคคลของตนเอง จะไม่มีการเผยแพร่ชื่อจริง
