# งานที่ว่าจ้าง

ใช้กับการมีส่วนร่วมที่คำแปลหรือเสียงบันทึกเป็นงานที่บุคคลหรือองค์กรว่าจ้างและจ่ายค่าตอบแทน
โดยบุคคลหรือองค์กรนั้นเป็นผู้ถือสิทธิและเลือกสัญญาอนุญาต ตัวบุคคลที่ทำงานที่ว่าจ้างจะไม่ถูกระบุตัวตนใน repository
และ id ในแต่ละแถวเป็นนามแฝง

* วัตถุประสงค์ การใช้งานที่ยอมรับได้ และการถอนข้อมูล เหมือนกับใน [`consent-collective.md`](consent-collective.md)
* ผู้ถือสิทธิกำหนดสัญญาอนุญาตของการมีส่วนร่วมแต่ละครั้งไว้ใน `contribution.yaml`
* มีการบันทึก `compensated: yes` แต่ไม่บันทึกจำนวนเงิน
* เสียงบันทึกของบุคคลใดต้องได้รับความยินยอมรายบุคคลจากคนนั้นด้วยเสมอ
  ([`consent-individual.md`](consent-individual.md)) ไม่ว่าใครจะเป็นผู้จ่ายเงิน

การมีส่วนร่วมภาษาชาวีชุดแรก (`2026-11_uyari_0001` ถึง `0003`) เป็นงานที่ว่าจ้าง สิทธิเป็นของ
