* Every language folder has the same five files. `contribution.yaml` names a consent template by file name
  (for example `consent-collective.md`), so the reference is the same in every language.
* [`takedowns.csv`](takedowns.csv) is the withdrawal register that every build applies.
* All versions say the same thing; English is the reference if they ever differ.

The problem Uyari addresses and its methodology are also translated: [`docs/`](../docs/README.md).
