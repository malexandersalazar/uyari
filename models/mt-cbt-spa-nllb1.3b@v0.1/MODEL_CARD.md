# mt-cbt-spa-nllb1.3b@v0.1

Text-to-text translation between **spa_Latn** and **cbt_Latn** (Shawi), both directions. Base model `facebook/nllb-200-distilled-1.3B` (CC BY-NC 4.0 (non-commercial; fine-tuned weights inherit it)), method `seq2seq`, trained by recipe `cbt-spa.mt.nllb-1.3b-3060` on build `data-2026.11`.

## Served by the demo

Registered as **fast** for cbt_Latn in `models/registry.yaml`. It is the demo's fast mode and the model for the public Hugging Face Space. The demo default is Muse Glimmer (open weights, on our own RTX 4090) once trained, whichever scores higher: the project claim is an open-weight Muse model on our own hardware. Trained on an RTX 3060 (12 GB) in pure bf16, recipe cbt-spa.mt.nllb-1.3b-3060.

## Data

* Build `data-2026.11` (`builds/data-2026.11/MANIFEST.json`), mt table content hash `30e205adc99e68ed`.
* 3575 human Shawi translations of 3575 Spanish chunks, from 3 contributions (provenance: human). Rows by split: {'test': 322, 'train': 2925, 'validation': 328} (spa_Latn).
* Contributions excluded (takedowns, revocations): none.
* Licenses on the rows: {'cc-by-4.0': 3575}.
* The Spanish side is synthetic, from a fixed design matrix (`primary/spa_Latn/matrix.yaml`). The first 10k chunks were generated in June 2026 with Claude Opus 4.8; generation has since moved to Meta: Muse Spark 1.3 Contributor produces the same cells at 3.3% of the cost (`reports/gen-comparison.md`), and Muse Glimmer on our own GPU at no API cost. Every chunk names the model that wrote it.
* Splits are assigned per paraphrase group, so no paraphrase of a test sentence is in training.

## Limitations

* About 3,600 sentence pairs, one variety (unspecified), four everyday domains. Health and civic language is thin (puente_civico has the fewest pairs).
* No Shawi recordings exist yet: this model is text only, and Shawi speech recognition in the demo is unmeasured.
* Output must be checked by a Shawi speaker before any use in health, legal or civic settings.

## Intended use

Communication access, education and language revitalization. Not for surveillance, targeting or profiling of speakers.
